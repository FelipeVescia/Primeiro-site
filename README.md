# Meu Primeiro Site

Projeto desenvolvido para praticar conceitos básicos de desenvolvimento web utilizando HTML, CSS e JavaScript.

## Tecnologias utilizadas

- **HTML5:** estrutura da página.
- **CSS3:** estilização e layout responsivo.
- **JavaScript:** interatividade.

## Funcionalidades

- Página inicial responsiva.
- Layout simples e organizado.
- Botão interativo utilizando JavaScript.
- Preparado para publicação no GitHub Pages.

## Como executar localmente

1. Clone este repositório:

   ```bash
   git clone https://github.com/SEU-USUARIO/meu-primeiro-site.git
   ```

2. Entre na pasta do projeto.
3. Abra o arquivo `index.html` no navegador.

## Publicação no GitHub Pages

1. Envie os arquivos para um repositório no GitHub.
2. Acesse **Settings → Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch `main` e a pasta `/ (root)`.
5. Clique em **Save**.

O endereço publicado será semelhante a:

`https://SEU-USUARIO.github.io/meu-primeiro-site/`
